# Research Notes

Your personal notes, summaries, and insights.

## Suggested Format

Create markdown files with:
- Source information (title, author, date)
- Key points and takeaways
- Your thoughts and analysis
- Related materials and cross-references

Example note template:
```markdown
# [Title of Source]

**Author:** Name
**Date:** YYYY-MM-DD
**Type:** Book/Article/Paper

## Summary
Brief overview...

## Key Points
- Point 1
- Point 2

## Personal Insights
Your thoughts...

## Related Materials
Links to related articles/books in this repo
```
